A new session knows only what was written down for it. When the work has more
than one source, every part of the hand-off must say which source it came from.
If it doesn't, the next session has to guess.

## What happened (S01E02)

- The first session transcribed a video (UTC clock) and an audio file (local
  plus two hours), and filed one record holding both texts with no labels.
- The resume session saw only that record, assumed the first part was the
  audio, and claimed crossed times. The course rejected it.
- The fix was to ask the first session (with the human's OK). It knew the
  order (video first), so the second claim passed.

## Rules

- Label each part of a hand-off with its source, even when the format you were
  given has no place for labels. Keep the labels in the log if the filed text
  must stay bare.
- Keep each source's answer in its own file or worker: one per recording here,
  so the two clocks never mixed in the reports.
- When a hand-off is missing a fact, ask whoever produced it. Don't infer the
  fact from a rejection: swapping the two times after the rejection would have
  passed, but only by luck.
- Write down the clock or units of each source next to every value from it.
